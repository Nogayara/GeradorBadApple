# 🎭 Gerador Bad Apple

Este script Batch permite criar uma versão estilizada do vídeo 'Bad Apple!!', substituindo as cores branca e preta por imagens personalizadas.

## 📌 Como funciona?

1. Arraste três arquivos para o CMD, na seguinte ordem:
   - Vídeo MP4 de Bad Apple, procure por sua conta e risco
   - Imagem que representará a parte branca
   - Imagem que representará a parte preta

2. O script renomeia os arquivos e processa o vídeo usando FFmpeg.

3. O resultado final será salvo como 'resultado.mp4'.

## 🚀 Requisitos

- Windows
- [FFmpeg](https://ffmpeg.org/download.html) instalado e configurado no PATH
